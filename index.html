AgentForge — Privacy Policy

Last updated: 3 October 2026 · Operated by KeyTechX

AgentForge is a desktop application that runs on the user's own computer. It helps its user write social media posts with AI assistants and, when the user chooses, publish them on the user's own LinkedIn profile or Facebook Pages through the platforms' official APIs. This policy explains what data the app handles.

What the app accesses

  • Facebook Pages (permissions pages_show_list, pages_read_engagement, pages_manage_posts): the list of Pages the user granted, and the ability to create posts on them. The app publishes a post only when the user presses Publish, or when the user has turned on scheduling for that post.
  • LinkedIn (scopes openid, profile, w_member_social): the user's name and member id, and the ability to create posts on the user's own profile when the user presses Publish.

Where data is kept

  • Access tokens are stored only on the user's computer, in the operating system's secure credential store. They are not sent to KeyTechX or to any third party.
  • Post texts, pictures and settings are stored only on the user's computer.
  • KeyTechX does not operate a server that receives, stores or shares the user's Facebook or LinkedIn data.

What the app does not do

  • It does not read private messages, friends lists or other people's data.
  • It does not sell, rent or share data with anyone, and does not use it for advertising.
  • It never asks for or stores the user's Facebook or LinkedIn password.

Data deletion

All data stays on the user's computer. To delete it, the user can press Disconnect in AgentForge (Social posts → Settings), which removes the stored tokens, and uninstall the app. Access can also be revoked at any time from Facebook (Settings → Business Integrations, or Business Settings for a system user) or LinkedIn (Settings → Data privacy → Permitted services). Because KeyTechX holds no copy of this data, there is nothing to delete on our side; requests can still be sent to the contact below.
